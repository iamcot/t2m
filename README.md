# t2m

Tool tạo nội dung ngắn cho anyLEARN bằng AI: lập kế hoạch tuần, viết kịch bản, dựng video 9:16 tối đa 60s (HTML → PNG → ffmpeg, TTS tiếng Việt), ảnh chế / truyện nhiều khung, rồi gửi lên Khám phá trong Vui học (chờ duyệt) và xuất file + caption cho Facebook, TikTok, YouTube, Zalo.

Chạy trên Mac của chủ sản phẩm. Bước AI chọn được `--ai api` (Anthropic API) hoặc `--ai claude-code` (`claude -p`).

Kế hoạch và tiến độ nằm ở repo anyLEARN:

- `plans/19-marketing-t2m.md` (task 19.B* là của repo này)
- `plans/PROGRESS.md`, Giai đoạn 5

Chưa có code. Việc đầu tiên: 19.B1 (khung CLI, schema kịch bản) và 19.B4 (template "Giới thiệu tính năng").
